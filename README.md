# HarvestLink

HarvestLink is a farmer-friendly web application that connects farmers and buyers for direct agricultural produce sales. It supports fair pricing, product discovery, order tracking, and market awareness without a middleman.

## Business System

- **Admin module:** dashboard metrics, product catalogue management, product publishing, order management, order status updates, and market trends.
- **Buyer module:** buyer signup and login, marketplace browsing, direct ordering, order history, and market trends.
- **Seller / Farmer module:** farmer signup and login, product listing, stock visibility, sales order tracking, and market trends.
- **Separate Admin access:** admin login is restricted to the seeded admin account and is not available through public signup.

## Requirements Covered

- Built only with HTML, CSS, and JavaScript.
- CSS Grid and Flexbox responsive layout.
- Signup and login using browser Local Storage.
- JavaScript module navigation and role-based dashboard redirection.
- Product listings, order placement, order status, and market trend views.
